# 企业微信自动发送 · 发送电脑安装和使用说明

## 这是什么

工作台里技术支持确认要发的内容（文字、图片、文件）后，由一台常开的 Windows 电脑上的「发送程序」替你操作企业微信：搜索群名、点开群、核对群名、把内容粘贴进输入框、按发送，再把成功或失败告诉工作台。

它做的事和人坐在电脑前一样，只是更快、每一步都会核对。它不破解企业微信，也不改动企业微信程序。

```
工作台「会话」里写好回复、加上图片文件，点「发送」并确认 → 排队 → 发送电脑上的程序操作企业微信发出 → 聊天记录里显示「已发出」或失败原因
```

## 一、准备

1. **一台常开的 Windows 10 或 11 电脑**，能打开工作台网址。
2. **在这台电脑上安装官方企业微信，登录专用客服账号**。这个账号要已经在各个客户群里。
3. **设置电脑不睡眠、不锁屏**。屏幕锁定后程序无法操作企业微信。
   - 设置 → 系统 → 电源：屏幕和睡眠都选「从不」
   - 设置 → 账户 → 登录选项：「需要登录」选「从不」，并关闭屏幕保护程序
   - 如果是用 Windows 自带的「远程桌面」连这台电脑，断开后桌面会被锁定，发送会失败。远程查看请用向日葵、ToDesk 这类软件，或者给电脑接一个显示器。
4. **企业微信的发送键保持默认的 Enter**。如果改成了 Ctrl+Enter，要在 config.ini 里把 `send_key` 改成 `ctrl+enter`。
5. **工作台口令**：部署工作台的同事在服务器上设置 `SEND_AGENT_TOKEN`（一串很长的随机字符），把同样的口令告诉你，安装时要填。

## 二、安装（只做一次）

1. 把 `windows-agent` 文件夹复制到这台电脑上，例如放到 `D:\wecom-agent`。
2. 双击 **1-install.bat**。它会自动安装 Python 和需要的组件，第一次大约几分钟。
3. 最后按提示填写三项：
   - 工作台后端地址，例如 `http://192.168.1.20:8000`
   - 发送程序口令（和服务器上的 `SEND_AGENT_TOKEN` 一样）
   - 给这台电脑起个名字，例如「客服电脑1」，会显示在工作台上
4. 看到「连接成功」就装好了。

## 三、校准（只做一次）

不同版本、不同屏幕的企业微信布局不一样，所以要让程序认一下搜索框、输入框在哪。企业微信升级、换显示器或改了屏幕缩放后，需要重新校准。

1. 建议先在企业微信里建一个测试群（拉一位同事），名字比如「工作台发送测试」。
2. 双击 **2-calibrate.bat**，按提示操作：
   - 程序会把企业微信窗口摆到固定位置。如果黑色窗口挡住了企业微信，把黑色窗口拖到旁边。
   - 按回车后有 5 秒时间，把鼠标移到企业微信左上方的**搜索框**上，停住，不要点。
   - 在企业微信里点开测试群，回到黑色窗口按回车，5 秒内把鼠标移到**聊天输入框**上，停住。
   - 输入测试群的名字，要和企业微信里显示的一字不差。
   - 程序会自己试一遍搜索、打开、核对群名。这一步不会发任何消息。
3. 看到「校准完成」就好了。如果失败，程序会生成一个 `diagnostics` 文件夹，把它打包发给开发人员。

## 四、试发一条

双击 **3-test.bat**，输入测试群名字。程序会先打开并核对这个群，这一步不发消息。然后它会问是否真的发一条测试消息，输入 `y` 并回车。到群里看一下有没有收到「【测试】这是售后工作台自动发送的测试消息，请忽略。」

接着它会问要不要试发图片和文件，再输入 `y`。到群里看是否依次收到一张蓝框测试图片、一个「测试文件.txt」和一句说明文字。如果企业微信粘贴文件时弹出了确认框，或者图片、文件没发出去，把 `logs` 文件夹发给开发人员，我们按真实界面调整。

## 五、日常运行

1. 双击 **4-start.bat**，让黑色窗口一直开着。工作台「会话」标题旁边会显示「发送电脑在线（客服电脑1）」。程序意外退出时会在 10 秒后自动重启。
2. 想开机自动运行，双击一次 **5-autostart.bat**。这需要电脑开机后自动登录 Windows，企业微信也设置为开机自动登录。
3. 程序运行时，不要使用这台电脑的鼠标键盘，否则会和程序抢操作。需要用电脑时，直接关掉黑色窗口就停止了。
4. **紧急停止**：把鼠标快速甩到屏幕任意一个角落，正在进行的发送会马上中止。

## 六、在工作台里怎么用

- 打开工作台的 **「会话」**，左边选一个群，右边是完整聊天记录，最下面是输入框。
- 输入框上方是 AI 建议。点 **「用这条建议」** 会把建议填进输入框，可以改完再发；发出后那条客户消息记为已处理。
- 点 **「📎 图片 / 文件」** 选择要发的图片或文件，也可以直接把截图粘贴（Ctrl+V）或把文件拖进输入框。一次最多 9 个，每个不超过 20MB。
- 点 **「发送」**（或按 Ctrl+Enter），会出现确认条：「将以客服账号把文字、1 张图片…发到企业微信群「XX」，确认发送？」。点 **「确认发送」** 才会真正发。
- 发送电脑会先发图片和文件，最后发文字。
- 发出的内容先显示在聊天记录最下面，状态是「排队等待发送」→「发送电脑正在发送…」→「已发出」。还在排队时可以点「取消发送」。
- **发送失败**：气泡变红，写明原因，这个群会留在「待处理」里。可以点「重新发送」，或者自己在企业微信里发出后点「我已手动发送」。如果失败时已经发出了一部分（比如图片发了、文字没发），原因里会写明哪些已经发出。
- 不想自动发，就点 **「只复制文字，我自己发」**。发送电脑离线、企业微信没登录、屏幕锁定时，标题旁会显示原因，这时只能复制文字手动发。

## 七、程序自动遵守的安全规则

- 只有人在工作台点了「确认发送」才会发。
- 工作台不知道群名，或者有两个同名的群，就不自动发，提示人工发送。
- 搜索结果里必须正好有一个完全同名的群才会点开。比如搜「某客户群」时出现了「某客户群二期」，不会点错。
- 点开后截屏识字，核对聊天标题就是这个群；校准时标题带人数，就要求标题带人数，避免打开同名的个人聊天。
- 粘贴后先确认内容确实在输入框里，按发送前再核对一次群名，发送后确认输入框已清空。图片、文件和文字每一条都这样核对。任何一步对不上都不发，并报告原因。
- 两条之间至少间隔 5 秒，每个群每小时最多自动发 20 条。
- 排队超过 10 分钟还没发出的自动取消，避免电脑恢复后才发出过时的回复。
- 正在发送时程序中断、结果不明的，标记为「结果未知」，不会自动重发，提醒人先去群里看一眼，避免重复发送。

## 八、常见失败和处理

| 工作台显示的原因 | 怎么办 |
| --- | --- |
| 发送电脑的屏幕已锁定 | 到发送电脑上解锁，并按「准备」第 3 条关闭锁屏 |
| 企业微信没有运行 / 未登录 | 打开企业微信，登录客服账号 |
| 企业微信窗口没有打开（可能缩到了托盘） | 双击右下角托盘里的企业微信图标 |
| 搜不到群「XX」 | 客服账号可能不在这个群里，或群名刚改过。确认后重新发送，或手动发送 |
| 搜索有多个同名结果 | 在企业微信里把重名的群改成不同名字，这次先手动发送 |
| 当前打开的聊天不是「XX」 | 可能有弹窗挡住了，或界面变了。到发送电脑上看一下，必要时重新校准 |
| 没能把回复填进输入框 | 输入框位置可能变了，重新校准 |
| 发送电脑下载图片或文件失败 | 发送电脑连不上工作台，检查网络后重新发送 |
| 粘贴图片或文件后输入框里没有内容 | 企业微信可能弹出了确认框，到发送电脑上看一下，把 logs 文件夹发给开发人员 |
| 按了发送键，但回复还留在输入框里 | 检查企业微信的发送快捷键是不是 Enter |
| 发送程序一直没有回报结果 | 先到群里看是否已发出，没发出再重新发送 |

失败时程序会在发送电脑的 `logs\screens` 文件夹里存一张截图，运行记录在 `logs\agent.log`，排查时可以一起发给开发人员。

## 九、目前的限制

- **还没有在真实的企业微信上跑过**。开发时没有 Windows 和企业微信客户端，搜索、点开、核对、发送的流程只在模拟环境测过。第一次使用请一定先用测试群完成「校准」和「试发」，有问题把 `diagnostics` 和 `logs` 文件夹发给开发人员调整。
- 程序只能确认「回复已离开输入框」，确认不了对方一定收到了。网络断开时，企业微信会在消息旁显示红色感叹号。
- 一次只处理一个发送，每条文字、图片或文件大约 5 到 10 秒。
- **图片和文件的发送也还没在真实企业微信上试过**。程序用「复制文件后粘贴」的方式放进输入框，和人手动操作一样；如果企业微信粘贴文件时弹出确认框，第一版会报失败，需要按真机情况调整。
- 视频、语音等其他类型暂不支持。
- 外部客户群要在工作台配置「客户联系」Secret 后才有群名，没有群名的群只能手动发送。
